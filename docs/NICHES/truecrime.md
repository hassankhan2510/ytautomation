# Niche Pack — True Crime / Mystery

Apply this whenever `meta.niche` is `truecrime`.

## Identity
- **channel:** `truecrime`
- **accentColor:** `#b91c1c` (deep blood red)
- **voice:** `en-US-ChristopherNeural` (tense) — Urdu/Hindi: `ur-PK-AsadNeural` / `hi-IN-MadhurNeural`
- **style string:** `dark-documentary`

## Tone & writing
- Suspenseful, measured, ominous. Build dread; withhold the reveal.
- Hook on the mystery ("She left for work and was never seen again").
- **Legally careful:** frame accusations as allegations; stick to the public record; no naming
  private individuals as guilty beyond court findings.
- End on the unsettling question or the lesson.

## Visual bias (keywords)
`dark alley night`, `police tape crime scene`, `foggy street`, `old case file`, `newspaper headline`,
`courthouse dark`, `abandoned house`, `rain window night`, `flashlight dark`. Mostly `image`, dim.

## Structure
Hook (the disappearance/crime) → the victim's world → the investigation → the twist → the outcome → the question.

## Example topics
"The case that was never solved", "The confession nobody believed", "How one clue cracked it open",
"The town with a dark secret", "The perfect crime that unraveled".
