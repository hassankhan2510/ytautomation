# Niche Pack — Motivation

Apply this whenever `meta.niche` is `motivation`.

## Identity
- **channel:** `motivation`
- **accentColor:** `#f59e0b` (amber / gold, sunrise energy)
- **voice:** `en-US-GuyNeural` (strong, warm) — Urdu/Hindi: `ur-PK-AsadNeural` / `hi-IN-MadhurNeural`
- **style string:** `punchy-explainer`

## Tone & writing
- Direct, punchy, energizing — but not cheesy. Earn the emotion with a real idea.
- Short lines. Hard hook ("Nobody is coming to save you. Good.").
- Use `center`, `quote`, and `stat` blocks for impact; keep pace fast.
- End on a line that lands like a punch and makes them want to move.

## Visual bias (keywords)
`sunrise runner silhouette`, `mountain summit`, `gym training dark`, `city at dawn`, `stormy sky`,
`person walking alone determined`, `ocean waves power`, `road ahead sunrise`. Prefer `video`, high energy.

## Structure
Hook (a hard truth) → the excuse people make → the reframe → the proof → the call to move.

## Example topics
"Discipline beats motivation", "Why comfort is killing you", "The 1% rule that changes everything",
"Nobody is coming to save you", "How to start when you feel like nothing".
