# public/music/

Drop background music tracks here (e.g. `cinematic_bed.mp3`), then set `meta.music` in
`script.json` to the filename.

**Use calm/cinematic/ambient beds only — no club/EDM/party music.** Full guidance and free,
monetization-safe sources: see [`docs/MUSIC.md`](../../../docs/MUSIC.md).

Music is optional — omit `meta.music` for a voice-only video.
