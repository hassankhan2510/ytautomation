# Brand Kit — Syndar · Cohort Zero · Farsight · TIL

Everything you need to set up each channel's pages (YouTube, Instagram, LinkedIn, TikTok, X).
Copy-paste the blocks below. Logos are in this folder as `*-logo.svg` (open in a browser →
screenshot/export to PNG for platforms that want an image). Colors match the videos' accent colors.

**Shared visual system** — dark, clean, one accent per brand.
- Ink / background: `#0A0A0B`  · Surface: `#16161A`  · Text: `#FFFFFF`  · Muted: `#9AA3AD`
- Font: Inter (or Montserrat / Space Grotesk) — bold for names, medium for body.
- Rule: one accent color per brand, used sparingly. Never more than one accent on screen.

> Handles are **suggestions** — check availability on each platform and grab the closest match
> consistently across all of them (same handle everywhere = one findable brand).
