# My images — your own photos for the reels

Put photos here (`.jpg`, `.png` or `.webp`) and **name each file for what it shows**:

| File name | What the AI understands |
|---|---|
| `Elon Musk.jpg` | a photo of Elon Musk |
| `elon-musk-2.jpg` | another photo of Elon Musk |
| `Tesla factory.png` | the Tesla factory |
| `Mohenjo daro ruins.webp` | the ruins of Mohenjo-daro |

Then run **Studio — Make Reel (one click)** and set **backgrounds** to one of:

- `my images + video` — your photos where they fit, stock footage everywhere else
- `my images + photo` — your photos where they fit, stock photos everywhere else
- `my images only` — your photos where they fit, generated backdrops everywhere else

The AI reads your script and puts each photo only into the scene(s) whose line is really about it
(it may use one photo in several scenes, and it never forces a photo in). The run summary lists
where each photo went and which ones it did not use.

**Upload:** on GitHub open this folder → **Add file → Upload files** (works from the phone too).
**Note:** this repository is public — anything in this folder is publicly visible, and only use
photos you have the right to use. Delete old photos when a reel is done so they don't get
matched into the next one.
